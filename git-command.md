# Основные команды и инструкции для системы контроля версий git:
- `git config --global user.name "Имя"` - _имя для репозиториев_
- `git config --global user.email "Email"` - _mail для репозиториев_
- `git congig --global --list` - _вывести все глобальные настройки git_

- `git clone ссылка_репозитория` - _клонирование репозитория для локальной работы_

- `git init` - _команда инициализации репозитория_
- `git add .` - _сделать из этой дерриктории репозиторий (добавить всё в индекс для отслеживания в git)_
- `git commit -m "комментарий"` - _сделать сохранение вотки локильно_
- `git remote -v` - _связи fetch и push_
- `git remote remove origin` - _удалить связь fetch и push_
- `git remote add origin ссылка_на_удалённый` - _связать удалённый и локальный репозитории_
- `git push origin feature_branch` - _отправить изменения с другой ветки_
- `git push -u origin <master>` - _отправить изменения на удалённый `master/main` git и запомнить связь_
- `git push` - _просто push по уже готовой связи_
- `git pull origin master` - _подтянуть все изменения из удалённого репозитория в локальный_

- `git status` - _состояние локального репозитория_
- `git branch` - _вывести все ветки_
- `git branch имя_ветки` - _создать новую\_ветку_
- `git checkout целевая_ветка` - _переключиться на целевую\_ветку_
- `git switch -c имя_ветки` - _создать нову\_ветку + переключиться на неё_
- `git rebase <main>` - _переместить коммиты из текущей ветки в целевую `main` на последний коммит_
- `git log --graph` - _история изменений_
- `git show` - _последний коммит и все его методанные + изменения в файле_

- `git update-ref -d HEAD` - _удалить текущий локальный коммит_
- `git commit --amend -m "комментарий"` - _изменить сообщения последнего коммита /добавить забытые файлы_
- `git revert <хеш>` - _создать новый коммит, отменив изменения из указанного `хеша`, `хеш` останется (безопасно)_

- `git push --force` - _принудительно отправить изменённый коммит, перезаписав историю **(только для своих веток)**_
- `git reset` - _удалить индекс, оставив изменения в файле_
- `git reset --soft HEAD~1` - _откатить последний коммит локально и сохранить все изменения в индексе_
- `git push origin <main> --force` - _удалить последний коммит на удалённом git, перезаписав ветку `main` **(только для своих веток)**_
